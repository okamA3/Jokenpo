# 🎮 Coleção de Minijogos e Utilitários em Python

Este repositório contém uma coleção de pequenos scripts interativos e minijogos desenvolvidos em Python, ideais para praticar lógica de programação, estruturas condicionais e interações com o usuário via terminal.

## 🚀 Projetos Incluídos

### 1. ⚽ Estatísticas de Jogadores (Participações em Gols)
Um script simples que mapeia listas de jogadores e suas respectivas participações em gols no ano, exibindo as informações formatadas na tela.

### 2. 🔢 Calculadora de Potenciação
Uma ferramenta simples e direta que solicita uma base e um expoente ao usuário, calcula a potência correspondente e exibe o resultado final.

### 3. ⚖️ Jogo de Par ou Ímpar
Um jogo clássico de Par ou Ímpar para dois jogadores. 
- O Jogador 1 escolhe entre Par (0) ou Ímpar (1).
- Ambos os jogadores digitam seus números.
- O programa soma os valores e determina automaticamente o vencedor com base na escolha inicial.

### 4. 🪨📄✂️ Jokenpô Simulator (Pedra, Papel ou Tesoura)
Simulador completo de Pedra, Papel e Tesoura para dois jogadores.
- Permite personalizar os nomes dos jogadores.
- Menu interativo para escolha das armas (1 - Pedra, 2 - Papel, 3 - Tesoura).
- Lógica precisa para identificar vitórias, derrotas ou empates.

## 🛠️ Tecnologias Utilizadas
- **Python 3**
- Entrada e saída de dados (`input` e `print` formatados com f-strings)
- Estruturas de controle de fluxo e condicionais (`if`, `elif`, `else`)
- Operadores aritméticos e lógicos
